LOGO yahan rakho (exact naam):
  logo.png   (transparent background, 512 px ya bada; square ya wide dono chalte hain)
  ya logo.svg / logo.webp / logo.jpg

Ek hi file rakhne se ye sab jagah khud lag jata hai:
  - header (upar left)        - footer
  - page khulte waqt ka animation (logo ghoom kar aata hai)
  - browser tab ka icon (favicon)   - WhatsApp/Facebook share preview

Baaki photos (story telling wali) bhi isi folder mein rakh sakte ho.
